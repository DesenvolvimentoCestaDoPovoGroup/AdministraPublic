# Administra: instalador

Este repositório só distribui o instalador de **atualização** do Administra. O código não fica aqui.

## Atualizar

- **No programa:** botão **Atualizar** (no alto da tela, à direita). Ele só aparece destacado quando há versão nova.
- **À mão:** baixe o `Administra-Instalador.exe` da [Release mais recente](../../releases/latest) e rode.

## Primeira instalação

A primeira instalação é feita com o **instalador da loja**, entregue pelo TI. Ele não fica aqui porque leva a
configuração de acesso ao banco. Depois da primeira instalação, clique em **Atualizar** para pegar a versão mais nova.

A instalação não pede administrador e mantém os dados de quem já usa (ficam em `%LOCALAPPDATA%\Administra`).
Se o Windows mostrar "Editor desconhecido": **Mais informações › Executar assim mesmo**.
